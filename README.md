# Tarea 6

## Descripción

Programa que realiza operaciones sobre un arreglo de productos y envía los datos a un servicio web mediante una solicitud HTTP POST.

## Operaciones realizadas

1. Filtrado de productos con stock disponible.
2. Aplicación de descuento sobre los precios.
3. Cálculo de la suma de precios.
4. Obtención del producto con mayor precio mediante distintos métodos.
5. Envío del inventario a un servicio web y procesamiento de la respuesta.

## Tecnologías utilizadas

* JavaScript
* Métodos de arreglos (`filter`, `map`, `reduce`, `find`, `toSorted`)
* `async/await`
* `fetch`
* JSON

## Requisitos

* Node.js 18 o superior.

## Ejecución

```bash
node tarea6.js
```

## Salida

El programa muestra en consola los resultados de cada operación y la respuesta recibida del servicio web.
